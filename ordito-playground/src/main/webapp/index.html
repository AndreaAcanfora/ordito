      One thread per node, one cell per entry, dyed by the term that wrote it. Solid cells are committed. Raft's job is to make every thread agree.

      ordito is open source (MIT). The simulator, the checker and Raft itself are compiled from Java to JavaScript with TeaVM; nothing here talks to a server.
